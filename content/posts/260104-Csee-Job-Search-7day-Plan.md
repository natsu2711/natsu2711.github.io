## 问题定义与策略

### 🎯 核心问题重新定义

使用**5W2H框架**分析：

| 维度 | 分析 |
|------|------|
| **What** | 跨行找CSEE相关工作 |
| **Where** | 北京/上海/深圳/杭州（一线城市机会更多） |
| **When** | 一周内（时间紧迫） |
| **Who** | 跨行背景，目标初级岗位 |
| **Why** | 快速入行，积累经验 |
| **How** | 高频投递 + 内推优先 + 突出可迁移能力 |
| **How much** | 接受初级/实习/外包薪资（先入行再优化） |

### 💡 核心策略

基于问题分析，采用**"快速入场"策略**：

1. **降低目标，先上车再补票**
   - ✅ 接受初级/实习/外包/测试岗位
   - ✅ 先入行积累经验
   - ✅ 6-12个月后再跳槽优化

2. **突出可迁移能力**
   - ✅ 快速学习能力（跨行本身就是证明）
   - ✅ 问题解决能力（用项目经验证明）
   - ✅ 跨领域视角（某些场景是优势）

3. **数量优先 + 内推加速**
   - ✅ 每天投递30+份（数量优先）
   - ✅ 内推优先级最高（跳过简历海选）
   - ✅ 多平台并行（不要只盯一个）

1. **测试开发工程师** ⭐⭐⭐⭐⭐

   - 容易积累经验

   - 沟通能力要求高
   - 技术门槛适中

   - 需要一定编程基础

   - 有成长空间

4. **运维开发工程师** ⭐⭐⭐⭐
   - 需要Linux基础
   - 容易入门

## 核心技能要求

### 📚 必备硬技能（按优先级）

#### Tier 1: 必须掌握（面试必考）

| 技能 | 要求程度 | 快速学习时间 | 学习资源 |

| **一门编程语言** | 能写简单程序 | 2-3天 | Python推荐 |

| **Linux基础** | 会常用命令 | 1天 | [Linux教程](https://www.runoob.com/linux/linux-tutorial.html) |

**快速学习路径**（5天突击）：
```
Day 1: Python基础（变量、循环、函数）
Day 2: 数据结构（数组、链表、栈、队列）
Day 3: 算法基础（排序、查找）
Day 4: Git + Linux基础
Day 5: 刷LeetCode简单题10道
```

#### Tier 2: 加分技能（面试加分）

| 技能 | 要求程度 | 快速学习时间 | 学习资源 |

| **Docker基础** | 理解容器概念，会run镜像 | 1天 | [Docker教程](https://www.runoob.com/docker/docker-tutorial.html) |
| **数据库基础** | 理解SQL，会简单查询 | 1天 | [SQL教程](https://www.runoob.com/sql/sql-tutorial.html) |
| **HTTP/网络基础** | 理解GET/POST、状态码 | 1天 | [HTTP教程](https://www.runoob.com/http/http-tutorial.html) |

#### Tier 3: 岗位特定技能

**嵌入式方向**：
- C语言基础
- 微机原理
- 操作系统概念

**前端方向**：
- HTML/CSS/JavaScript基础
- Vue/React框架（了解即可）

**后端方向**：
- Java/Go/Python后端框架

**AI方向**：

### 📅 Day 1: 定位与简历准备

#### 上午（3小时）：明确目标

**Task 1.1: 确定目标岗位类型（1小时）**

```
决策树：
你有编程基础？
├─ 有 → 选择哪个方向？
│   ├─ 嵌入式/硬件相关 → 方向1（芯片/半导体）

    ├─ 测试开发工程师
    ├─ 技术支持工程师

```

## 🎯 最终建议

### 成功的五个关键

1. **数量优先，不要挑剔**
   - 每天投递30+份
   - 接受初级/实习/外包
   - 先上车再补票

2. **突出可迁移能力**
   - 快速学习（自学案例）
   - 问题解决（项目经验）
   - 沟通协作（团队经历）

3. **内推优先，多渠道并行**
   - 先找人内推
   - 同时在多平台投递
   - 不要只盯一个渠道

4. **快速学习，针对性准备**
   - 5天突击基础技能
   - 根据目标岗位调整
   - 准备项目Demo

5. **持续优化，不要放弃**
   - 根据反馈调整简历
   - 分析面试失败原因
   - 保持投递节奏

### ⚠️ 常见陷阱

1. **目标过高** ❌
   - 不要直接投高级岗位
   - 不要一开始就要求高薪

2. **只盯着大厂** ❌
   - 中小公司机会更多
   - 初级岗位小厂更容易进

3. **简历一成不变** ❌
   - 针对不同岗位调整
   - 根据反馈持续优化

4. **投递后不跟进** ❌
   - 主动沟通HR
   - 面试后及时跟进

5. **面试准备不足** ❌
   - 至少准备3个STAR案例
   - 练习自我介绍到流畅

### 📈 评估标准

**一周成功的标志**：
- 投递总数：100+份
- 面试邀请：3-5个
- Offer数量：1-2个（初级/实习）

**如果没有达到**：
- 继续投递（不要停）
- 分析原因，调整策略
- 拓展更多渠道
- 降低目标岗位
